<h1> The case against open-source software. </h1>
<p>Although open source offers strong advantages, it also brings significant drawbacks, most of which stem from the software's open nature. 

It is important to acknowledge that, although open-source software can improve an application's safety through transparency, that same openness can also, at times, introduce risks to the application's safety. By allowing people to see behind the curtain at how the software functions, open-source software can enable people to find errors and exploits in the code, but this goes both ways. Those who find an error or exploit might use it to their advantage, tricking the system in ways that benefit them. From this perspective, building your application or platform on open-source software is equivalent to letting hackers and exploiters see and discover all the program's vulnerabilities. This might result in the company needing far more coders to keep up with the added attention to the program's flaws, but as said before, many people will read the code and choose to help the program's owners fix the malfunction. Whether this makes up for the added vulnerabilities of sharing your code with everyone can only be judged case by case.  

Another problem with open source is the general public's lack of interest in modifying software. Open source is both free and highly modifiable, which is one reason so many companies have chosen to use it; yet for the general public, these features can seem unnecessary. Although open-source software indeed allows for a far more personalised experience, it is also true that to be able to obtain this experience, some knowledge of coding as well as general tech savvy is needed, something many people do not possess. In reality, many people would gladly pay for closed-source software that is easy to use and convenient, especially if it allows them to use the same system they have grown accustomed to.  </p>
